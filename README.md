# Fresh-Fridge

A mobile app whose sole purpose is to prevent food from expiring unnoticed by tracking all food items that have a best-by, use-by, or estimated expiration date. The app makes logging fast, reminders smart (not annoying), and usage obvious.

## Quick Start

**To run this app in Xcode:**

1. Clone this repository:
   ```bash
   git clone https://github.com/yourusername/Fresh-Fridge.git
   cd Fresh-Fridge
   ```
2. Open `FreshFridge.xcodeproj` in Xcode (double-click the file)
3. Select a simulator or device
4. Press **⌘R** to build and run!

That's it! The project is fully configured and ready to run.

**For detailed instructions, see:** [`FreshFridge/README.md`](FreshFridge/README.md)

## Features

- 📷 Barcode scanning for quick item entry
- 📝 Manual entry with quick templates
- 🔄 FIFO batch tracking (oldest items consumed first)
- 📊 Urgency-based dashboard (Use Today, Next 3 Days, etc.)
- 🔔 Smart notifications based on item type
- 🔍 Search and filter by location
- 📸 Optional photo support
- ✋ One-handed optimized UX
